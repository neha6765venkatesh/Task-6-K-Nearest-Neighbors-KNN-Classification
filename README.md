Iris KNN Classification Project
This project demonstrates how to apply the K-Nearest Neighbors (KNN) algorithm to the Iris dataset using scikit-learn. It includes data preprocessing, model training with various K values, performance evaluation, and visualization of decision boundaries.

 Files
Iris.csv — The dataset used for classification.

Features
Data Normalization using StandardScaler

Model Training with different values of K

Accuracy Evaluation and Confusion Matrix visualization

Decision Boundary Plotting using PCA-reduced features

 Requirements
Python 3.x

pandas

numpy

scikit-learn

matplotlib
